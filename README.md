# Simple Interest Calculator

A simple command-line calculator written in Bash that computes simple interest based on user inputs:
- **Principal amount** ($P$)
- **Annual rate of interest** ($R$)
- **Time period in years** ($T$)

## Formula
$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

## How to Run

1. Make the script executable:
   ```bash
   chmod +x simple-interest.sh
   ```
2. Execute the script:
   ```bash
   ./simple-interest.sh
   ```
3. Enter the requested values when prompted (Principal, Rate of Interest, and Time in years).
